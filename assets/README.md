# FORM 27 image set

The images in `wp-content/themes/form27/assets/images/` were generated with the built-in OpenAI image generation tool. The repository keeps optimized AVIF and WebP derivatives; lossless generation sources remain in the local Codex image archive and are not committed.

## Shared art direction

- Use case: `product-mockup` for product and material shots, `photorealistic-natural` for case studies.
- Palette: graphite `#171918`, milky off-white `#F2F1EC`, aluminum grey, one restrained signal orange `#F05A28`.
- Materials: anodized aluminum, mineral plaster, honed graphite stone.
- Lighting: cool architectural ambient light with controlled 3000K or 4000K beams.
- Avoid: logos, text, watermarks, people, brass, wood-heavy hospitality styling, neon, science-fiction styling and implausible mounting.

All scenes and products are fictional. They are portfolio assets, not documentation of manufactured products or completed client projects.
